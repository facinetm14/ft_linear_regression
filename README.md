# Linear regression from training to prediction

A small Python regression project with separate training, prediction, and scoring entry points. Start with the [input dataset](data/data.csv), inspect the [gradient-descent implementation](trainer/gradient_descent.py), and follow the fitted parameters into the [predictor](predictor/predict.py). The [scoring script](scoring/main.py) and [visualization](visualization/data_graph.py) provide two ways to inspect model behavior.
